## 1. はじめに

### Voiloid でできること

テキストチャンネルに書かれたメッセージを、Bot がボイスチャンネルで読み上げます。
声・読み方・読み上げるチャンネルなどは、ブラウザの **Web コンソール** から設定します。

### 用語

| 用語 | 意味 |
|---|---|
| Web コンソール | 設定を変更するためのサイト。Discord のアカウントでログインします |
| サーバー管理者 | Discord のサーバーで「サーバーの所有者」「管理者」「サーバー管理」のどれかの権限を持つ人。サーバーの設定を変更できます |
| デフォルト音声 | サーバーで使う標準の声。マイボイスを設定していない人の発言はこの声で読みます |
| マイボイス | 自分の発言を読むときの声。すべてのサーバーで共通です |
| エンジン | 音声合成ソフトの種類。VOICEVOX・AivisSpeech・COEIROINK があります |
| Worker | 音声を作るコンピューター。運営が用意する **公式Worker** と、利用者が自分で動かす **自鯖Worker** があります |
| サブボット | 同じサーバーの別のボイスチャンネルで同時に読み上げるための、追加の Bot |

### ログイン

Web コンソールを開き、「Discordでログイン」を押します。Discord の認可画面で「認証」を押すとログインできます。
Voiloid が受け取るのは、ユーザー名・アイコン・参加しているサーバーの一覧だけです。Discord のパスワードは Voiloid に送られません。

ログインすると、あなたが **管理権限を持つサーバー** が「Servers」に表示されます。

## 2. Bot をサーバーに導入する

サーバー管理者が行います。

1. Web コンソールの「Servers」を開く
2. 導入したいサーバーのカードで「Botを追加」を押す
3. Discord の画面で、サーバーが選ばれていることを確認して「認証」を押す

導入すると、カードに「Bot Online」と表示され、「管理」から設定を変更できるようになります。

Bot に必要な権限は「接続」「発言」「ニックネームの変更」です。ボイスチャンネルの権限で「接続」「発言」を拒否していると、そのチャンネルには入れません。

## 3. 読み上げを始める・終える

### コマンドで呼ぶ（既定）

1. 読み上げたいボイスチャンネルに入る
2. 読み上げたいテキストチャンネルで `/join` を実行する
3. Bot がボイスチャンネルに入り、そのテキストチャンネルの発言を読み上げます

終えるときは `/leave` を実行します。ボイスチャンネルから人がいなくなると、Bot は 30 秒後に自動で退出します。

### チャンネルを固定する

サーバーの「General」で「チャンネルを固定する」を選ぶと、決まったテキストチャンネルを決まったボイスチャンネルで読み上げます。
「ボイスチャンネルに自動参加」をオンにすると、誰かがそのボイスチャンネルに入ったときに Bot も自動で入ります（`/join` が要りません）。

### 同時にいくつかのボイスチャンネルで読み上げる

1 つの Bot が入れるボイスチャンネルは、1 サーバーにつき 1 つです。
別のボイスチャンネルでも同時に読み上げたいときは、**サブボット** をサーバーに招待してください（[5-1. Overview](#5-1-overview概要)）。
サブボットがいれば、2 つ目のボイスチャンネルで `/join` したときに、空いているサブボットが入ります。

---

## 4. コマンド一覧

| コマンド | 説明 | 使える人 |
|---|---|---|
| `/join` | あなたがいるボイスチャンネルに Bot を呼び、実行したテキストチャンネルの読み上げを始めます | 全員 |
| `/leave` | 読み上げを終え、Bot をボイスチャンネルから退出させます | 全員 |
| `/skip` | 読み上げ中・待機中のメッセージを飛ばします | 全員 |
| `/voice` | あなたのマイボイスを確認します | 全員 |
| `/dict add 単語 読み方` | 辞書に単語の読み方を登録します（同じ単語があれば上書き） | サーバー管理者 |
| `/dict remove 単語` | 辞書から単語を削除します | サーバー管理者 |
| `/dict list` | 辞書に登録されている単語の一覧を表示します | サーバー管理者 |

`/dict` を使える人は、Discord の「サーバー設定 → 連携サービス → Voiloid」で変更できます。

## 5. サーバーの設定（サーバー管理者）

「Servers」でサーバーの「管理」を押すと、次のタブがあります。変更した設定はすぐに読み上げに反映されます。

### 5-1. Overview（概要）

- 読み上げの状態、今の声、使っている Worker、今日読み上げたメッセージの数
- 今読み上げているテキストチャンネルとボイスチャンネル
- **Bot**: メインの Bot と各サブボットが、このサーバーにいるかどうか。いない Bot は「招待」から個別に招待できます（サブボットがあるサービスでだけ表示されます）

### 5-2. General（基本設定）

| 項目 | 説明 |
|---|---|
| 読み上げ方法 | 「コマンドで呼び出す」（`/join` したチャンネルを読む）か「チャンネルを固定する」 |
| 読み上げるテキストチャンネル / 参加するボイスチャンネル | 「チャンネルを固定する」のときに指定します |
| ボイスチャンネルに自動参加 | 「チャンネルを固定する」のとき、誰かがボイスチャンネルに入ったら Bot も入ります |
| URL を読み上げる | オフなら URL を「URL省略」と読みます |
| 最大文字数 | 1 つのメッセージで読む文字数の上限（1〜1000） |
| 長いメッセージの扱い | 「切り詰める」（上限までを読み、「以下略」と読む）か「スキップ」（読まない） |

### 5-3. Voice（声）

- **サーバーのデフォルト音声**: エンジン・話者・スタイル・話速・音高・抑揚を選びます。右側の「プレビュー」で試聴できます
- **使えるエンジン**: スイッチをオフにしたエンジンは、このサーバーでは使いません。
  - そのエンジンの声は選べなくなり、読み上げにも使われません
  - マイボイスがオフのエンジンの声の人は、このサーバーではデフォルト音声で読まれます
  - デフォルト音声に使っているエンジンはオフにできません。先にデフォルト音声を別のエンジンに変えてください

### 5-4. Dictionary（辞書）

読み間違える単語の読み方を登録します。メッセージ中の「単語」を「読み」に置き換えて読み上げます（英字の大文字・小文字は区別しません）。
登録できる数には上限があります（既定は 1000 件）。`/dict` コマンドでも同じ辞書を編集できます。

### 5-5. Worker（音声を作る場所）

このサーバーの音声を、どの Worker で作るかを選びます。通常は「自動」のままで問題ありません。

| 設定 | 説明 |
|---|---|
| 自動 | 公式Worker と、このサーバーに共有された自鯖Worker から、空いているものを使います |
| 公式のみ | 公式Worker だけを使います |
| 自鯖優先 | このサーバーに共有された自鯖Worker を優先します。「公式Workerへのフォールバック」をオンにすると、自鯖Worker が使えないときに公式Worker を使います |
| Workerを指定 | 選んだ自鯖Worker だけを使います |

「自鯖優先」「Workerを指定」で使えるのは、このサーバーに **「サーバーで共有」** で接続された自鯖Worker です。接続のしかたは [自鯖Worker ガイド](self-hosted-worker.md) を参照してください。

### 5-6. Profile（Bot のプロフィール）

このサーバーでの Bot の名前とアイコンを変えます。他のサーバーには影響しません。
サーバーにサブボットがいる場合は、サブボットにも同じ名前とアイコンが反映されます。後から招待したサブボットにも、参加したときに反映されます。

Discord の制限により、短い時間に何度も変更すると失敗することがあります（10 分に 5 回まで）。

## 6. 自分の声（マイボイス）

「Settings」の「マイボイス」で、自分の発言を読む声を選びます。すべてのサーバーで共通です。
「サーバーのデフォルト音声を使う」をオンにすると、各サーバーのデフォルト音声で読まれます。

マイボイスのエンジンが、あるサーバーで使えない場合（そのサーバーの Worker が対応していない、またはサーバーでオフにされている）は、そのサーバーではデフォルト音声で読まれます。
どのサーバーでどちらの声になるかは、「Settings」の「サーバーごとの読み上げ」で確認できます。

自分の自鯖Worker を、あるサーバーに「自分専用」で接続すると、そのサーバーでも自鯖Worker のエンジンの声で読まれるようになります。

## 7. 読み上げのルール

| メッセージの内容 | 読み方 |
|---|---|
| Bot の発言 | 読みません |
| メンション（@ユーザー・#チャンネル・@ロール） | 名前を読みます |
| URL | 「URL省略」（「URL を読み上げる」がオンなら、そのまま読みます） |
| コードブロック（\`\`\`〜\`\`\`） | 「コードブロック」 |
| 伏せ字（\|\|〜\|\|） | 「伏せ字」 |
| カスタム絵文字 | 絵文字の名前を読みます |
| 日時の表示（`<t:…>`） | 読みません |
| 添付ファイル | 最後に「添付ファイル」と読みます |
| 最大文字数を超えた部分 | 「切り詰める」なら上限までを読んで「以下略」、「スキップ」ならそのメッセージを読みません |

辞書の置き換えは、上の整形の後に行います。

## 8. その他の画面

| 画面 | 内容 |
|---|---|
| Dashboard | 管理しているサーバーの状態、Bot と Worker の状態 |
| Workers | 自分の自鯖Worker の一覧と追加。公式Worker の稼働状況と混雑度 |
| Voices | 今使える声の一覧と試聴 |
| Usage | 管理しているサーバーで読み上げた文字数・回数（公式Worker と自鯖Worker の内訳、日別、サーバー別） |
| Settings | アカウント、マイボイス、テーマ（ダーク / ライト）、言語（日本語 / English） |

画面の上部に、運営からのお知らせが表示されることがあります。

## 9. よくある質問

**Q. `/join` しても Bot が来ません。**
- 先にボイスチャンネルに入ってから `/join` してください
- Bot がそのボイスチャンネルに「接続」「発言」できるか、チャンネルの権限を確認してください
- 別のボイスチャンネルで読み上げ中の場合、サブボットがいなければ入れません
- サーバーの読み上げが運営によって一時停止・利用停止されている場合は、画面上部のお知らせやサーバーの表示を確認してください

**Q. 一部のメッセージが読まれません。**
- Bot の発言、最大文字数を超えて「スキップ」になったメッセージは読みません
- 「チャンネルを固定する」の場合、指定したテキストチャンネル以外は読みません

**Q. 自分の声がマイボイスになりません。**
そのサーバーでマイボイスのエンジンが使えない可能性があります。「Settings」の「サーバーごとの読み上げ」を確認してください。

**Q. Servers にサーバーが表示されません。**
そのサーバーで「管理者」または「サーバー管理」の権限が必要です。権限をもらった直後は、数分たってから再読み込みしてください。

**Q. ログアウトしたい。**
左下のアカウントの横にあるボタンからログアウトできます。
